**vccs** is an unofficial Vue 3 port of [Recharts](https://recharts.org/). You build a chart
from components, and each component owns one part of it.

## What is vccs?

vccs brings the component-based charting of Recharts to Vue 3. Instead of one large options
object, you compose a chart from components such as `<AreaChart>`, `<Bar>`, `<Line>` and
`<Tooltip>`, and customize parts with slots.

## Charts

| From Recharts | Component |
| --- | --- |
| Area, Bar, Line, Scatter | [`AreaChart`](/charts/area-chart), [`BarChart`](/charts/bar-chart), [`LineChart`](/charts/line-chart), [`ScatterChart`](/charts/scatter-chart) |
| Mixed series | [`ComposedChart`](/charts/composed-chart) |
| Pie, Radar, Radial bar | [`PieChart`](/charts/pie-chart), [`RadarChart`](/charts/radar-chart), [`RadialBarChart`](/charts/radial-bar-chart) |
| Funnel | [`FunnelChart`](/charts/funnel-chart) |
| Hierarchy and flow | [`Treemap`](/charts/treemap), `SunburstChart`, [`Sankey`](/charts/sankey) |

| Added by vccs | Use it for |
| --- | --- |
| [`BarList`](/charts/bar-list) | Ranked lists with inline bars |
| [`Sparkline`](/charts/sparkline) | Small trend lines inside text or tables |
| [`Tracker`](/charts/tracker) | Status over time, one block per period |
| [`Heatmap`](/charts/heatmap) | Values on a grid of two categories |
| [`CalendarHeatmap`](/charts/calendar-heatmap) | Daily values over a year |
| [`CohortChart`](/charts/heatmap#cohort-retention) | Retention by cohort and period |
| [`JourneySankey`](/charts/journey-sankey) | Paths that users take, step by step |

## What works the Vue way

- **Models:** `v-model:active-index` on `Tooltip`, `Bar`, `Pie` and the standalone charts;
  `v-model:range` on `Brush`; `v-model:hidden` on `Legend`.
- **Slots:** custom shapes, dots, ticks, labels and tooltip content are named slots.
- **Events:** typed Vue events; item events receive `(item, index, event)`.
- **Typed rows:** `defineChartComponents<Row>()` checks `data-key` and types tooltip payloads.
- **Synchronized charts:** charts with the same `sync-id` share the tooltip and the Brush range.
- **Server rendering:** charts render on the server and hydrate without layout jumps.
- **Motion:** enter, update and exit animations that follow `prefers-reduced-motion`.
- **Accessibility:** every chart has an accessible name, and item charts support the keyboard.

## When to use vccs

Use vccs when you need to:

- Add data visualization to a Vue 3 application
- Migrate existing Recharts code from React to Vue
- Build interactive, animated charts with a composable API
- Customize chart appearance beyond what config-driven libraries offer

## Quick example

```vue [App.vue]
<script setup>
import { Area, AreaChart, CartesianGrid, Tooltip, XAxis, YAxis } from 'vccs'

const data = [
  { name: 'Jan', uv: 4000 },
  { name: 'Feb', uv: 3000 },
  { name: 'Mar', uv: 2000 },
  { name: 'Apr', uv: 2780 },
  { name: 'May', uv: 1890 },
  { name: 'Jun', uv: 2390 },
]
</script>

<template>
  <AreaChart
    :data="data"
    :height="300"
  >
    <CartesianGrid stroke-dasharray="3 3" />
    <XAxis data-key="name" />
    <YAxis />
    <Tooltip />
    <Area
      type="monotone"
      data-key="uv"
      stroke="#f97316"
      fill="#f97316"
    />
  </AreaChart>
</template>
```
