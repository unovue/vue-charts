A heatmap places rows of data in a grid: one field picks the column, one picks the row, and a third sets the color. Use it for patterns over two dimensions, such as visits by weekday and hour.

## Weekday and hour

::chart-demo{name="Visits Heatmap" description="Visits per weekday and hour, colored continuously." src="heatmap-charts/weekday-hour-heatmap"}
::

Columns and rows follow the order in which values first appear in `data`. Pass `x-domain` and `y-domain` to set the order yourself or to show columns that have no data. Rows with the same column and row are added up. Column labels thin out on narrow screens so they never overlap.

## Cohort retention

`CohortChart` is a heatmap for retention. Each row is a cohort, for example everyone who signed up in January. `values[0]` is the cohort's size and `values[n]` is how many were still active `n` periods later. Each cell shows the share of the cohort. Periods a cohort has not reached yet stay blank, so the grid forms a triangle.

::chart-demo{name="Cohort Retention" description="Monthly signup cohorts and their retention." src="heatmap-charts/cohort-retention-chart"}
::

Set `mode="count"` to show the counts instead of percentages.

## Heatmap props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `Record<string, any>[]` | **required** | Rows with a column, a row and a value |
| `x-key` / `y-key` / `data-key` | `string` | `'x'` / `'y'` / `'value'` | Fields for column, row and value |
| `x-domain` / `y-domain` | `(string \| number)[]` | order of appearance | Column and row order |
| `color` / `empty-color` | `string` | series 1 token / `var(--v-charts-muted)` | Full and empty color |
| `levels` | `number` | `0` | `0` mixes colors continuously; a number gives that many steps |
| `colors` | `string[]` | — | Explicit fill per level, from empty to full |
| `max` | `number` | largest value | Value that reaches full color |
| `fill-missing` | `boolean` | `true` | Draw pairs without data as empty cells |
| `show-values` | `boolean` | `false` | Draw each value on its cell when it fits |
| `value-format` | `(value, cell) => string` | `String` | Text for a value |
| `x-label-format` / `y-label-format` | `(key) => string` | `String` | Text for column and row labels |
| `x-labels` / `y-labels` | `boolean` | `true` | Show the labels |
| `gap` / `radius` | `number` | `2` / `2` | Space between cells and corner radius |
| `active-index` | `number \| null` | — | Rendered cell position, for `v-model:active-index` |
| `width` / `height` / `aspect` | `number` | full width, 28 px per row | Size |

## CohortChart props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `Record<string, any>[]` | **required** | One row per cohort, oldest first |
| `cohort-key` / `values-key` | `string` | `'cohort'` / `'values'` | Fields for the cohort name and its counts |
| `mode` | `'percent' \| 'count'` | `'percent'` | Share of the cohort size, or raw counts |
| `period-label` | `(period) => string` | `String` | Column heading per period |
| `color` / `empty-color` | `string` | as Heatmap | Colors |
| `active-index` | `number \| null` | — | Rendered cell position, for `v-model:active-index` |
| `locale` | `string` | `'en-US'` | Number formatting |

Both share the Tracker's [events, `#cell` slot and keyboard navigation](/charts/tracker#events-and-slots). Event payloads are `{ x, y, value, rows }`.

Bind `v-model:active-index` to control selection; `null` clears it. Pointer and keyboard changes request an update. See [Events and v-model](/guides/events-and-models) for control precedence.
