## PieChart props

`<PieChart>` takes the [chart container props](/charts/chart-containers), including the polar
props. Its tooltip shows one sector at a time.

## Pie props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data-key` | row path or accessor | **required** | Field with the value |
| `name-key` | row path or accessor | `'name'` | Field with the sector name; without it, sectors are named by row index |
| `data` | `Array` | the chart's `data` | Rows for this pie |
| `cx`, `cy` | `number \| string` | `'50%'` | Center |
| `inner-radius` | `number \| string` | `0` | Inner radius; above `0` draws a donut |
| `outer-radius` | `number \| string \| function` | `'80%'` | Outer radius |
| `start-angle` | `number` | `0` | Start angle in degrees |
| `end-angle` | `number` | `360` | End angle in degrees |
| `padding-angle` | `number` | `0` | Gap between sectors in degrees |
| `min-angle` | `number` | `0` | Minimum sector angle, so small values stay visible |
| `fill` | `string` | series palette per sector | Sector fill; `<Cell>` sets one sector |
| `stroke` | `string` | `'var(--v-charts-background, #fff)'` | Sector outline |
| `label` | `boolean` | `false` | Show a label outside every sector |
| `label-line` | `boolean` | `true` | Draw a line from the sector to its label |
| `active-index` | `number \| null` | — | Active sector, for `v-model:active-index` |
| `name` | `string \| number` | — | Name in the legend and tooltip |
| `legend-type` | `LegendType` | `'rect'` | Legend icon |
| `tooltip-type` | `'none'` | — | Set `'none'` to leave the series out of the tooltip |
| `hide` | `boolean` | `false` | Hide the series |
| `class` | `string` | — | Class on the series layer |
| `is-animation-active` | `boolean` | the chart's value | Animate this series |
| `transition` | `ChartTransition` | the chart's value | Timing and easing of data changes |

Events: `@click`, `@mouseenter`, `@mouseleave` with `(sector, index, event)`, `update:activeIndex`, and `@animation-start`, `@animation-end`.

## Pie slots

| Slot | Props | Description |
| --- | --- | --- |
| `#shape` | `PieSectorDataItem & { isActive }` | Replace a sector |
| `#activeShape` | `PieSectorDataItem & { isActive }` | Replace the active sector |
| `#label` | `PieSectorDataItem & { index }` | Replace a sector label |
| default | — | `<Cell>` for per-sector colors, `<LabelList>` |
