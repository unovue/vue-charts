Every default color in vccs comes from a CSS variable with a neutral fallback. Set the variables on any parent element, and charts follow your theme, including dark mode, without overriding SVG attributes.

```css
.dashboard {
  --v-charts-grid: #e4e4e7;
  --v-charts-text: #71717a;
}
.dark .dashboard {
  --v-charts-grid: #27272a;
  --v-charts-text: #a1a1aa;
}
```

Series colors are props, so they can use variables too:

```vue
<Bar data-key="desktop" fill="var(--chart-1)" />
```

## Tokens

| Token | Used for | Fallback |
|---|---|---|
| `--v-charts-grid` | grid lines, polar grid, reference lines and areas | `#ccc` |
| `--v-charts-axis` | axis lines, tick lines, brush and error-bar strokes | `#666` |
| `--v-charts-text` | tick labels and text | `#666` (ticks), `#808080` (Text) |
| `--v-charts-cursor` | tooltip cursor line and band | `#ccc` |
| `--v-charts-muted` | bar and radial bar backgrounds, empty Tracker and calendar cells | `#eee` |
| `--v-charts-background` | dot fills and separators between sectors and nodes | `#fff` |
| `--v-charts-series` | series color when you do not pass one | `#3182bd` (Line, Area, SunburstChart), `#808080` (Pie, Funnel, Radar, RadialBar, Treemap), `#0088fe` (Sankey) |
| `--v-charts-status-up`, `-degraded`, `-down`, `-maintenance` | Tracker status colors | `#22c55e`, `#f59e0b`, `#ef4444`, `#3b82f6` |
| `--v-charts-inactive` | hidden legend items | `#a3a3a3` |
| `--v-charts-focus` | keyboard focus outline | `Highlight` |
| `--v-charts-tooltip-background` | default tooltip background | `#fff` |
| `--v-charts-tooltip-border` | default tooltip border | `#ccc` |
| `--v-charts-label-foreground` | text on filled cells and Treemap nodes | automatic black/white for known opaque fills; otherwise `currentColor` |
| `--v-charts-tooltip-foreground` | default tooltip text | `#000` |

## Class names

Every rendered part has a stable class with the `v-charts-` prefix, for example `.v-charts-bar-rectangle`, `.v-charts-cartesian-axis-tick-value` or `.v-charts-tooltip-wrapper`. Use them for anything the tokens do not cover.

## Text on fills

Known opaque colors use whichever of `#ffffff` and `#0a0a0a` has higher contrast.
For CSS variables, color mixes and translucent fills, set `--v-charts-label-foreground`
on the chart or a cell's parent. Choose it against the resolved, composited fill in
both themes. A variable's fallback does not establish its actual color.
The override also takes precedence over the automatic choice for opaque fills.
Tooltip text uses `--v-charts-tooltip-foreground`; series colors appear as swatches.
BarList text inherits your page color, with the bar color limited to a 20% tint.
