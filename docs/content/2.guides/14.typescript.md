vccs ships complete types. In `.vue` files with Volar, slot props and event payloads are inferred without annotations:

```vue
<Tooltip>
  <template #content="{ active, payload, label }">
    <div v-if="active">{{ label }}: {{ payload?.[0]?.value }}</div>
  </template>
</Tooltip>
```

## Row-typed charts

A child component cannot see the type of its chart's `data`, so `data-key` accepts any string by default. To check data keys against your row type, create typed components once per row type:

```vue
<script setup lang="ts">
import { defineChartComponents } from 'vccs'

interface Visit { date: string, desktop: number, mobile: number }
defineProps<{ visits: Visit[] }>()

const { AreaChart, Area, XAxis, Tooltip } = defineChartComponents<Visit>()
</script>

<template>
  <AreaChart
    :data="visits"
    :height="300"
  >
    <XAxis data-key="date" />
    <Area data-key="desktop" />
    <Area data-key="mobile" />
    <!-- data-key="tablet" is a type error -->
    <Tooltip />
  </AreaChart>
</template>
```

`defineChartComponents` returns the same components; it only changes their types and costs nothing at runtime. Tooltip payload items are typed with `payload: Visit`.

## Exported types

`ChartTransition` (the `transition` prop), `ChartPointerState` (chart event state), `BrushIndex`, `TooltipActiveIndex` and `LegendHidden` (model values), and the props and slot props of every component.
