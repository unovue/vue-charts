Charts are responsive by default. Each numeric `width` or `height` prop fixes that dimension; a dimension without a number follows the box the chart sits in. This applies to every chart, including Sankey, Treemap and SunburstChart.

## Full width, fixed height

The most common chart: as wide as its container, 300 px high.

```vue
<BarChart :data="data" :height="300">
  <Bar data-key="value" />
</BarChart>
```

## Fixed size

```vue
<BarChart :data="data" :width="600" :height="400">
  <Bar data-key="value" />
</BarChart>
```

## Fill the parent

Without a size, the chart fills its parent. Give the parent a definite height:

```vue
<div class="h-80 w-full">
  <LineChart :data="data">
    <Line data-key="value" />
  </LineChart>
</div>
```

## Keep an aspect ratio

```vue
<LineChart :data="data" :aspect="16 / 9">
  <Line data-key="value" />
</LineChart>
```

The height follows the width. In shadcn-vue, the `ChartContainer`'s `aspect-video` class does the same.

## ResponsiveContainer

`<ResponsiveContainer>` is kept for code ported from Recharts. It sizes a box (`width`, `height`, `aspect`, `minWidth`, `minHeight`, `maxHeight`) and the chart inside fills it. New code does not need it.

```vue
<ResponsiveContainer width="100%" :height="300">
  <BarChart :data="data">
    <Bar data-key="value" />
  </BarChart>
</ResponsiveContainer>
```

## Server rendering

The server cannot measure the page, so a responsive chart renders at an initial size and scales into its box until the browser measures it. The default is 640 px wide and 360 px high (or `640 / aspect`); a fixed `height` or `width` is used as given. Set `initial-dimension` close to the real size for the sharpest first paint:

```vue
<AreaChart :data="data" :height="250" :initial-dimension="{ width: 900, height: 250 }">
  <Area data-key="value" />
</AreaChart>
```

See [Nuxt and SSR](/guides/nuxt-and-ssr) for the details.

## Chart margins

The `margin` prop adds space between the chart edges and the plot area. This chart uses `margin: { top: 20 }` to make room for labels above bars:

::chart-demo{name="Chart with Margins" description="Bar chart with top margin for LabelList positioning." src="bar-charts/label-bar-chart"}
::

The default margin is `{ top: 5, right: 5, bottom: 5, left: 5 }`. Increase it for axis labels outside the plot, `<LabelList position="top">` on bars, or a legend outside the chart.

## Common sizing issues

**Chart is not visible:** the parent has no height. Give the chart a `height`, give the parent a height, or use `aspect`.

**Chart is too small:** large margins or a wide Y axis use up the space. Check `margin` and the axis `width`.
