Charts are responsive by default. Set both numeric `width` and `height` props for a fixed-size chart, or let the chart fill its parent. This applies to categorical charts, Sankey, Treemap, and SunburstChart.

## Explicit dimensions

Pass `width` and `height` directly to the chart component:

```vue
<BarChart :width="600" :height="400" :data="data">
  <Bar data-key="value" fill="#f97316" />
</BarChart>
```

## Responsive sizing by default

When either numeric dimension is absent, the chart fills its parent and measures its own box with a `ResizeObserver` after mount. No wrapper component is needed:

```vue
<!-- Full width, fixed height -->
<LineChart :style="{ height: '300px' }" :data="data">
  <Line data-key="value" fill="#f97316" />
</LineChart>

<!-- Fill a sized parent (flex/grid cell, etc.) -->
<div style="width: 100%; height: 300px">
  <LineChart :data="data">
    <Line data-key="value" />
  </LineChart>
</div>

<!-- Keep an aspect ratio -->
<LineChart :aspect="16 / 9" :data="data">
  <Line data-key="value" />
</LineChart>
```

Both numeric dimensions select fixed sizing. Otherwise give the parent (or chart style) a definite height, or use `aspect` to derive height from width. The `responsive` prop has been removed.

## Responsive sizing with `ResponsiveContainer`

Alternatively, wrap your chart in `<ResponsiveContainer>` to fill its parent container. All the chart demos on this site use `ResponsiveContainer` — here's an example:

::chart-demo{name="Responsive Chart" description="A chart using ResponsiveContainer to fill its parent width." src="bar-charts/simple-bar-chart"}
::

`ResponsiveContainer` is a compatibility box: it applies width, height, aspect, and minimum/maximum dimensions. The child chart measures itself. The container forwards `initialDimension` to charts that do not set their own, and its `onResize` callback reports changes to the box.

Common patterns:

```vue
<!-- Fixed height, full width -->
<ResponsiveContainer width="100%" :height="300">
  ...
</ResponsiveContainer>

<!-- Percentage of parent -->
<ResponsiveContainer width="100%" height="100%">
  ...
</ResponsiveContainer>

<!-- With aspect ratio -->
<ResponsiveContainer width="100%" :aspect="16 / 9">
  ...
</ResponsiveContainer>
```

## Chart margins

The `margin` prop adds internal padding between the chart edges and the drawing area. This chart uses `margin: { top: 20 }` to make room for labels above bars:

::chart-demo{name="Chart with Margins" description="Bar chart with top margin for LabelList positioning." src="bar-charts/label-bar-chart"}
::

Default margin is `{ top: 5, right: 5, bottom: 5, left: 5 }`.

Increase margins when you need space for:
- Axis labels that extend beyond the chart area
- `<LabelList>` with `position="top"` on bars
- Legend positioned outside the chart

## Common sizing issues

**Chart not visible**: Give the parent a nonzero width and height, or use `aspect` on the chart or container.

**Chart too small**: Check that margins are not consuming most of the available space.

**SSR rendering**: Nuxt and other Vue SSR applications render the full SVG before any browser measurement. Responsive charts start at `initialDimension`, defaulting to `{ width: 640, height: 360 }`, or height `640 / aspect` when `aspect` is set. The SVG viewBox and 100% CSS dimensions scale this geometry into the box. The first client render uses the same geometry; after mount, measurement updates the layout. A zero-sized box retains the initial geometry until it has a usable size.

```vue
<BarChart :aspect="2" :initial-dimension="{ width: 800, height: 400 }" :data="data">
  <Bar data-key="value" :is-animation-active="false" />
</BarChart>
```

Animated series can start with empty geometry in SSR HTML. Set `:is-animation-active="false"` on the series when the server must render complete data shapes.

Chart pointer handling starts after the first valid measurement so scaled initial geometry does not produce incorrect tooltip coordinates.
