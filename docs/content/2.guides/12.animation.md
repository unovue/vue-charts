Every chart element moves with the same timing, so bars, lines and areas in one chart arrive and settle together.

| Phase | Duration | Curve |
|---|---|---|
| First appearance | 0.6 s | ease-out (fast start, soft landing) |
| Data change | 0.5 s | ease-out |
| Removed bar, radial bar or treemap node | 0.25 s | ease-in |

## Data changes slide, they do not morph

Elements are matched by their category (the `data-key` of the category axis, or the `name` of a sector), not by their position in the array. When a time window moves, the bars slide; when a series gets longer, new points grow out of their neighbour; removed points fold into the points that stay. Points of one line, area or pie keep a shared timing, so the shape never crosses itself. An interrupted animation continues from what is on screen.

Give every row a unique category value to get this behaviour. Rows without a category fall back to their index.

## Tune the motion

Every animated element accepts a `transition` prop. It replaces the default timing for that element:

```vue
<Bar data-key="desktop" :transition="{ duration: 0.3, ease: 'easeOut' }" />
<Line data-key="mobile" :transition="{ type: 'spring', stiffness: 200, damping: 25 }" />
```

The type is exported as `ChartTransition`.

## Turn it off

```vue
<Bar data-key="desktop" :is-animation-active="false" />
```

Charts also follow the operating system's *reduce motion* setting: data changes snap to their final state and the tooltip stops gliding.

## React to animation

```vue
<Bar data-key="desktop" @animation-start="onStart" @animation-end="onEnd" />
```

Labels appear after the transition with a short fade.
