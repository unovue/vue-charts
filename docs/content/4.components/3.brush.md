```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Brush } from 'vccs'
import type { BrushStartEndIndex } from 'vccs'

const range = ref<BrushStartEndIndex | null>({ startIndex: 0, endIndex: 5 })
</script>

<template>
  <Brush
    v-model:range="range"
  />
</template>
```

`null` shows all rows and hides the travellers. Without a range prop, Brush manages its range. Supplied ranges stay under parent control; `update:range` requests a change. Finite bounds are floored, clamped and ordered. Empty data and non-finite bounds use `null`.
